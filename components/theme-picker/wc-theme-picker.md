# wc-theme-picker

Lets the user switch between automatic, dark and light themes.

Note: you must add the following before any CSS to prevent FOUC:

```js
//key is currently hardcoded to "site-theme"
const value = localStorage.getItem(key);
document.documentElement.style.setProperty("--theme", value);
```
