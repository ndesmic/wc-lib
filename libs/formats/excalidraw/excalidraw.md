# Excalidraw

Supports converting the excalidraw JSON format to SVG

## Supported element types and features

| Feature   | Supported |
| --------- | --------- |
| Rectangle | ✔         |
| Ellipse   | ✔         |
| Text      | ✔         |
| Line      | ✔         |
| Arrow     | ✔         |
